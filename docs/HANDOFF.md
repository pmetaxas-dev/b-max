# B-MAX: οδηγός παράδοσης (για όποιον φτιάχνει το UI)

Το B-MAX είναι ένας βοηθός εστίασης για ανθρώπους με ΔΕΠΥ. Ζει σε Chrome extension και σε τοπικό Go server.
Ο **Max** (λάμπα με σώμα) είναι ο βοηθός σου: μιλάς μαζί του, του λες τον στόχο ζωής και τα tasks της ημέρας,
και εκείνος τα ιεραρχεί, σε παρακολουθεί και σε καθοδηγεί. Ο **πλανήτης** μεγαλώνει όσο προχωράς προς τον στόχο.

Αυτό το αρχείο λέει τι δουλεύει ήδη, πού είναι το UI, και τι δεν πρέπει να χαλάσεις.

## Πώς τρέχει

```bash
cd 'E:/2026_projects!/openhackathon-demo/demo-hackathon/server'
export GROQ_API_KEY="το-key"          # απαραίτητο για chat και μικρόφωνο
export GROQ_MODEL="openai/gpt-oss-120b"   # προαιρετικό (προεπιλογή: llama-3.3-70b-versatile)
go run ./cmd/server                    # ακούει στο 127.0.0.1:8787
```

Ταχύτητα: το chat μπορεί να χρησιμοποιεί άλλο μοντέλο από τον planner με `GROQ_CHAT_MODEL` (π.χ. `llama-3.3-70b-versatile`, γρήγορο). Κάθε μοντέλο έχει δικό του όριο ανά λεπτό στο Groq, οπότε χωρίζει και το φορτίο. Ο server γράφει σε κάθε κλήση μία γραμμή `groq <μοντέλο>: <χρόνος>, prompt N tokens`, ώστε να φαίνεται γιατί κάτι αργεί. Όταν το Groq βάλει όριο (429), ο Max λέει "δοκίμασε ξανά σε N δευτερόλεπτα" αντί να σωπαίνει.

Άλλες μεταβλητές: `GROQ_STT_MODEL` (προεπιλογή `whisper-large-v3`), `PORT`, `DATA_DIR` (προεπιλογή `./data`).
Στο Git Bash βάζε τα paths με `!` σε **μονά** εισαγωγικά.

Extension: `chrome://extensions` → Developer mode → Load unpacked → φάκελος `extension`. Μετά από κάθε αλλαγή στον
κώδικα του extension πάτα ↻ στην κάρτα του B-MAX.

Έλεγχος πριν το commit: `bash scripts/check.sh` (Go vet + tests, tests του extension, κανόνες κώδικα). Πρέπει να τελειώνει με `ALL CHECKS PASSED`.

Εργαλεία δοκιμής: το κουμπί ⚙️ πάνω δεξιά στο dashboard (Reset profile, Fast timings που κάνει τις αναμονές 10 φορές πιο σύντομες, ρολόι για "επόμενη μέρα").

## Τι κάνει η εφαρμογή

- **Onboarding chat:** ο Max χαιρετάει, εξηγεί τον πλανήτη και ρωτάει το όνειρο (στόχο ζωής) και τα tasks της ημέρας. Ο **χρόνος του κάθε task** είναι κεντρικός για την ιεράρχηση: ρωτάει "μέχρι πότε και πόση ώρα" μία φορά· αν δεν ξέρεις, **εκτιμά μόνος του** από το είδος του task (ένα email ~10′, μελέτη python ~90′) και το λέει ως πρόταση, και τη μέρα μετά ρωτάει μία φορά αν η εκτίμηση ταιριάζει.
- **Δυναμική ιεράρχηση:** το LLM βάζει σε σειρά τα tasks σε κάθε συνομιλία (προθεσμία, διάρκεια, στόχος). Το πρώτο ξεκινά αυτόματα (δεν υπάρχει κουμπί έναρξης). Ο server ξαναδιατάσσει μόνος του όταν πλησιάζει μια προθεσμία, και ο Max ρωτάει αν θες να αλλάξεις task.
- **Παρακολούθηση:** μετράει χρόνο σε σχετικές σελίδες (browser tasks). Όταν περάσει ο χρόνος ή η προθεσμία ρωτάει "τελείωσες;". Αν αποσπαστείς σε YouTube κτλ. σε γυρνάει στο task και στη σελίδα που ήσουν. Αν δουλεύεις άλλο task από αυτό με προτεραιότητα, σου το θυμίζει. Το επόμενο πρωί κάνει recap ό,τι έμεινε.
- **"Πού ήμουν;":** κρατάει journal και απαντά στο chat. Ο Max δίνει και μικρό πρώτο βήμα ("Βοήθησέ με να ξεκινήσω").
- **Πλανήτης:** ακολουθεί τον στόχο ζωής. Κάθε task έχει επίπτωση 0-3 και ο στόχος μέγεθος, οπότε το μπάνιο δεν κουνάει τον κόσμο. Το τικ ζητά επιβεβαίωση και έχει αναίρεση. **Στις κακές μέρες** (30′ σε sites απόσπασης χωρίς κανένα task ή βράδυ χωρίς τίποτα τελειωμένο) ο πλανήτης αποκτά **σύννεφα και κεραυνούς**. Είναι διάθεση και όχι τιμωρία: η πρόοδος δεν μειώνεται ποτέ και ένα task καθαρίζει τον ουρανό.
- **Σεντούκι ιδεών (💎):** ένα απλό κουτί όπου ο χρήστης πετάει ό,τι του έρχεται στο μυαλό (γράφοντας εκεί, στο chat ή στη λάμπα). Οι ιδέες **μένουν** για αργότερα· κάθε μία μπορεί να γίνει σημερινό task ή να διαγραφεί (με ερώτηση). Ο Max τις θυμίζει (α) το Σαββατοκύριακο, μία φορά την εβδομάδα, όταν κάνεις διάλειμμα, και (β) όταν περάσουν 15′ σε sites απόσπασης χωρίς να έχεις τελειώσει κανένα task εκείνη τη μέρα, με μία ιδέα, μία φορά τη μέρα, χωρίς να λέει γιατί.
- **Λάμπα σε κάθε σελίδα:** πάτημα → βγαίνει ο Max με σώμα και συζητά (task, ιδέα, ερώτηση). Μαζεύεται μόνος του.
- **Φωνή:** μικρόφωνο στο dashboard **και σε κάθε tab** (στη λάμπα, μέσω κρυφής σελίδας του extension, οπότε η άδεια δίνεται μία φορά): ηχογράφηση → Groq Whisper, καλό για ελληνικά με αγγλικές λέξεις, με 3″ αναμονή πριν σταλεί ώστε να διορθώσεις. Ο Max μιλάει (chat και pop-ups σε κάθε tab).
- **Γλώσσα:** διακόπτης EL/EN πάνω δεξιά (αλλάζει κείμενα, απαντήσεις Max, μικρόφωνο, λάμπα).
- **Ήχος εστίασης:** 🎧 (Βαθιά ηρεμία, Βροχή, Κύματα).
- **Προσβασιμότητα:** βλ. παρακάτω.

## Προσβασιμότητα (τυφλοί, χαμηλή όραση, μόνο πληκτρολόγιο)

- **♿ panel** στο dashboard: "Ο Max μιλάει" (κοινό flag για όλα τα tabs), "Πες μου πού βρίσκομαι", μεγάλο κείμενο, υψηλή αντίθεση, λίστα συντομεύσεων.
- **Συντομεύσεις** (αλλάζουν στο `chrome://extensions/shortcuts`):
  - `Alt+Shift+S`: ο Max λέει προφορικά πού βρίσκεσαι (task τώρα, τι ακολουθεί, πλανήτης). Δουλεύει σε κάθε tab, χωρίς να ανοίξει τίποτα.
  - `Alt+Shift+M`: ανοίγει ο Max στην τρέχουσα σελίδα με τον κέρσορα στο πεδίο του.
  - `Alt+Shift+V`: μιλάς στον Max σε οποιοδήποτε tab. Αν υπάρχει ανοιχτό pop-up, **απαντάς σε αυτό με τη φωνή σου** ("ναι", "όχι τώρα", "πάμε πίσω") και ο Max πατάει το σωστό κουμπί.
  - `Alt+Shift+K`: μετάβαση στα κουμπιά ενός pop-up.
- **Pop-ups που μιλάνε:** όταν ο Max εμφανίζεται σε κάποιο tab (check-in, επιστροφή, προθεσμία, υπενθύμιση) διαβάζει το μήνυμα, τις επιλογές και πώς να απαντήσεις (`chrome.tts`, permission `tts`).
- Skip link, landmarks, live regions (ανακοινώνονται οι απαντήσεις του Max), focus που επιστρέφει στο κουμπί μετά το Esc, σεβασμός του `prefers-reduced-motion`, περιγραφή του πλανήτη με λόγια (`iframe title` και προφορική κατάσταση).
- Οι αρχές κώδικα: μόνο πραγματικά `<button>`/`<input>` (ο `a11y.js` αρνείται handler σε div), ορατό focus, τίποτα που να βασίζεται μόνο σε χρώμα.

## Πού είναι το UI

| Τι | Αρχείο | Σημείωση |
|---|---|---|
| Σελίδα dashboard (CSS και σκελετός) | `extension/dashboard/dashboard.html` | **Όλο το CSS είναι στο `<style>`**. Μεταβλητές χρωμάτων στο `:root` (`--bg`, `--accent`, `--surface`…). Εδώ αλλάζεις όψη. |
| Λογική και σχεδίαση dashboard | `extension/dashboard/dashboard.js` | Συναρτήσεις: `renderNow` (κάρτα ΤΩΡΑ), `renderLater` (λίστα), `renderA11yPanel`, `openDrawer`/`closeDrawer` (chat), `greet` (χαιρετισμός). Τα κείμενα EL/EN είναι στο `UI`. |
| Το chat (component) | `extension/shared/chat.js` | Κλάσεις: `.chat`, `.chat-log`, `.msg-max`/`.msg-user`, `.chat-form`, `.suggest-menu`. Κείμενα EL/EN στο `TEXT`. |
| Ο Max στις ιστοσελίδες | `extension/content/page-object.js` | Το CSS είναι ένα string (`const CSS`) μέσα σε Shadow DOM. Κάρτες, chat της λάμπας. |
| Popup εργαλειοθήκης | `extension/summary/summary.html` και `.js` | Μίνι πλανήτης, motivation, 3 tasks. |
| Ο Max (SVG και animations) | `extension/shared/max/` | `max.css` (float, blink, σώμα), `max.svg`, `max-body.svg`. Οι κινήσεις wave και σκέψης είναι στο `<style>` του dashboard (`.waving`, `.thinking`). |
| Κείμενα καρτών στις σελίδες | `extension/shared/i18n.js` | EL/EN. |
| Ο πλανήτης | `extension/shared/planet/planet.html` | Έτοιμο Three.js, **μην το πειράξεις**. |

## Τι να μην αλλάξεις

- **Τα ids και οι κλάσεις που χρησιμοποιούν τα tests και ο κώδικας:** `#chat-input`, `.chat-form`, `.chat-log`, `.msg`, `.now`, `#now-card`, `.fab`, `.drawer`, `#drawer-close`, `.max-peek`, `.lang button[data-lang]`, `#a11y-btn`, `#sound-btn`, `#dev-gear`. Αν τα αλλάξεις, τρέξε `bash scripts/check.sh`.
- **Κανόνας του service worker:** καθόλου `setTimeout`/`setInterval` στο `extension/background/*` ή σε ό,τι εισάγουν. Ο χρόνος ζει στον Go server (ο έλεγχος τρέχει στο `check.sh`).
- **Η λογική δεν μπαίνει στο JavaScript:** κανόνες (προτεραιότητες, χρόνοι, πρόοδος) είναι στον Go (`server/internal/domain` και `application`). Το UI μόνο δείχνει και στέλνει.
- **Μορφή του API:** τα JSON σχήματα (`/chat`, `/tasks/action`, `/state/full`…) χρησιμοποιούνται από τα tests.

## Δομή του server

`server/internal/domain` (κανόνες, χωρίς I/O) → `application` (use cases: `chat.go`, `tasks_life.go`, `status.go`, `app.go`) → `api` (HTTP) · `groq` (chat, planner, Whisper) · `storage` (JSON αρχείο).
Σχέδιο και αποφάσεις: `architecture-plan-v2.md`, `NOTES.md`, `docs/architecture.md`.

## Πρόταση ροής για το demo (3 λεπτά)

1. **Reset profile** (⚙️) → ο Max χαιρετάει και εξηγεί τον πλανήτη. Πες τον στόχο και δύο tasks με μικρόφωνο.
2. Δες το ΤΩΡΑ με την ιεράρχηση. Πάτα το EL/EN για να δείξεις τη γλώσσα.
3. Άνοιξε YouTube: ο Max σε γυρνάει στο task. Πάτα "Βοήθησέ με να ξεκινήσω".
4. Πάτα τη λάμπα σε μια σελίδα και πρόσθεσε task με τη φωνή σου.
5. `Alt+Shift+S` με κλειστά μάτια: ο Max λέει πού είσαι και πώς πάει ο πλανήτης.
6. Τικ σε task (επιβεβαίωση) → ο πλανήτης μεγαλώνει.

## Γνωστά όρια

- Το μικρόφωνο σε ιστοσελίδες χρειάζεται μία φορά άδεια (ανοίγει ένα μικρό παράθυρο). Οι συντομεύσεις πλήκτρων δεν μπορούν να δοκιμαστούν αυτόματα· δοκίμασέ τες σε πραγματικό Chrome.
- Η φωνή σου στέλνεται στο Groq για μεταγραφή και δεν αποθηκεύεται.
- Ο ήχος εστίασης παίζει όσο είναι ανοιχτό το dashboard.
- Η ανίχνευση "δουλεύεις άλλο task" χρειάζεται λέξεις-κλειδιά (τις βάζει το LLM για browser tasks). Για offline δουλειά ("να απλώσω ρούχα") ο Max βασίζεται μόνο στον χρόνο.
- Δεν έχει γίνει δοκιμή με screen reader σε πραγματικό NVDA/JAWS/VoiceOver, μόνο έλεγχος του markup και της φωνής.
